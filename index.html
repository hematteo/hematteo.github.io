2026First authorPreprint · Under review

Sparse Readout Prism

Explaining Logit-Lens Scores in Features Instead of Tokens

Matteo He, William F. Shen, Xinchi Qiu, Nicholas D. Lane

Which readout features make a token score high?

I factorize the model’s output weights into sparse features, then account for token scores through signed feature contributions and an explicit residual. Selected Qwen3.5 dictionaries retain 88.7–90.0% top-token agreement on held-out states after readout replacement.

Paper Code Dictionaries BibTeX
Method & scope

The method uses the unembedding weights to learn reusable readout features. It decomposes selected logits and token margins, with reconstruction, replacement, sign, residual, and confound checks. This is an account of the readout’s contribution, rather than a claim to explain the model’s entire computation.

2026First authorManuscript under review

Learning to Read Out

Unembedding Dynamics in Language Model Pretraining

Matteo He, William F. Shen, Alex Iacob, Andrej Jovanovic, Xinchi Qiu, Nicholas D. Lane

When does information in a hidden state become available to the model’s own readout?

I study the output readout as a learned measurement channel during pretraining. Trajectory crosscoders, readout swaps, and controlled probes separate hidden-state availability from native-readout expression across model checkpoints.

Code Guided notebooks BibTeX
Method & scope

I extract output-weight snapshots over pretraining, fit sparse dictionaries to their trajectories, and use checkpoint-level interventions and ablations to study the readout’s development. The code release includes reusable analysis components, CPU-only examples, and a map from experiments to paper figures. The manuscript is under review; the public release currently provides code and notebooks.

03
2024Honours dissertation · St Andrews

Automating the Interpretability of Attention Heads in LLMs

Can language models generate and test explanations of attention-head behavior?

I built a GPT-2 interpretability pipeline using an LLM explainer and simulator to propose and evaluate functional explanations. This work started my interest in making interpretability methods systematic and testable.

Approach & evaluation

The dissertation paired GPT-4 as an explainer with GPT-3.5 as a simulator. Iterative evaluation improved distribution-based error metrics by 25% and reduced token errors from 366 to 157 on the dissertation’s evaluation. These are results from that experimental setup, rather than a general benchmark claim.
